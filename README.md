I work at the intersection of offensive security and engineering: researching
vulnerabilities, building reproducible proof-of-concepts, and automating the
work that makes security teams faster and more consistent.

My main interests are web and API security, adversary simulation, cloud and
identity security, security tooling, and AI-assisted developer workflows.

## How I work

- Keep research scoped, authorized, and reproducible.
- Turn findings into clear evidence, impact analysis, and remediation guidance.
- Prefer secure defaults, explicit approvals, isolation, and useful audit trails.
- Build tools that are practical to run, test, and maintain.
